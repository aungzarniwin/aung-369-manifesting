"၃၊ ၆၊ ၉ တို့၏ ကြီးမြတ်ပုံကို သိရှိပါက စက္ကဝါ၏ သော့ချက်ကို ရရှိပါလိမ့်မည်။" — နီကိုလာ တက်စလာ

GitHub Pages တွင် အခမဲ့ လွှင့်နည်း

  1. GitHub တွင် 369-manifestation အမည်ဖြင့် repository အသစ်ဆောက်ပါ။
  2. ထို repo ထဲတွင် index.html ဖိုင်တစ်ခု ဆောက်ပါ။
  3. ဤ HTML Code များကို index.html ထဲသို့ ကူးထည့်ပါ။
  4. Commit changes နှိပ်ပါ။
  5. Settings → Pages သို့သွားပါ။
  6. Branch နေရာတွင် main ကိုရွေးပြီး Save နှိပ်ပါ။
  7. ၁ မိနစ်အတွင်း သင့် Website လွှင့်ပြီး ဖြစ်ပါလိမ့်မည်။
